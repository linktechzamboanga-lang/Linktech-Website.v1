Help and Instructions

Learn how to use LinkTech ID Maker Mo.

1. Create an ID Template

Open ID Designer, choose portrait or landscape, and add text, shapes, images, photo frames, and signature frames.

2. Design Front and Back

Use the Front Side and Back Side controls to create both sides of your ID card.

3. Lock Your Design

Save your template and lock the design to protect its layout. Unlock it when you need to rearrange design elements.

4. Manage Employees

Add employee information, photos, and signatures. Edit existing records without creating a new employee record.

5. Batch Printing

Select employees, choose the paper and card dimensions, then preview the print layout before printing.

6. Backup Your Workspace

Export a JSON backup regularly. Keep a separate copy of your backup file for recovery.

Important Printing Reminder

Complete both the front and back template before selecting Front and Back printing. Check the print preview, paper size, orientation, margins, and card dimensions before printing.
