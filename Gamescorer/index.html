How to Use Game Scorer

Step-by-step instructions for tournament operators.

01

Create a Tournament

Open Tournament, enter the event name, select a sport, choose the format, date and venue, and save your settings.

02

Register Teams

Open Teams & Players. Add the team name, captain, logo, color and player names. Register each team.

03

Generate the Bracket

Generate your match schedule. Review the pairings before starting the competition.

04

Operate Live Scoring

Select a match, update scores with the plus and minus controls, manage periods and use the timer when needed.

05

Save Match Results

Confirm the final score and save the match. The tournament engine uses the result to advance teams.

06

Share Results

Use the share controls to prepare tournament schedules and score updates for social media.

07

Backup Your Tournament

Export your JSON backup regularly. Import the file later to restore the tournament on a supported device.

Important data protection: Tournament data is stored in this browser on this device. Clearing browser data, uninstalling the browser or changing devices may remove access to the saved data. Export a backup regularly.
