How to use Cheque Generator

  1. Measure your cheque's width and height with a ruler, then enter the dimensions.
  2. Enter the amount. The app converts it into words automatically.
  3. Enter the payee, date, and optional memo.
  4. Tap an element in the preview. Drag it using touch or a mouse to position it.
  5. Use the selected-element settings to change its text, font, color, size, and width.
  6. Save the layout in this browser or export a JSON backup for future use.
  7. Print a test on plain paper, measure the output, and adjust the X/Y offsets if necessary.

Privacy: Your saved layout stays in this browser unless you export or print it. Do not use this tool to alter a cheque's official security features.
